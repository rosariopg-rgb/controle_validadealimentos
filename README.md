# controle_validadealimentos
Sistema de controle de validade de alimentos - Projeto para fins acadêmicos.

Sistema em linguagem C
Objetivo é: 
- Cadastro de alimentos.
- Consulta de alimentos.
- Atualização de informações.
- Exclusão de registros.
- Controle de validade.
- Identificação de alimentos vencidos.
Um sistema criado sem conexão com banco de dados.

Modelagem do Banco de Dados
O projeto possui:

MER – Modelo Entidade-Relacionamento // 
DER – Diagrama Entidade-Relacionamento.

5 Tabelas Criadas:

- Categoria
- Local de Armazenamento
- Situação
- Alimento
- Lote

 Parte SQL
O código SQL foi dividido em três partes:
- Criação das tabelas.
- Inserção de dados.
- Criação de relatórios.

6. Relatórios

Foram criados 8 relatórios para consultar as informações do estoque, como:

- Lista de alimentos.
- Produtos vencidos.
- Produtos que vencem hoje.
- Quantidade por categoria.
- Quantidade por local de armazenamento.
- Resumo dos lotes por situação.
- Produtos próximos do vencimento.
- Alimentos com mais de um lote.
