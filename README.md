# controle_validadealimentos
Sistema de controle de validade de alimentos - Projeto para fins acadêmicos.

Sistema em linguagem C
Objetivo é: 
- Cadastro de alimentos.
- Consulta de alimentos.
- Atualização de informações.
- Exclusão de registros.
- Controle de validade.
- Identificação de alimentos vencidos.
Um sistema criado sem conexão com banco de dados.
